# 网页点到点导航（室外测试版）

现已另行接入高德自动步行路线，自动规划用法见同目录《高德自动导航使用说明.md》。以下说明介绍保留的手动航点模式。

继续使用原公网控制网页。电脑上的视觉计算程序已增加导航计算；网页新增 OSM 地图和航点导航面板。

## 设置路线

1. 车上 iPhone 刷新网页，重新开启后置摄像头，并点击“允许本机定位与运动数据”。保持手机页面在前台。
2. 地图底图来自 OpenStreetMap，网页会自动加载；绿色圆点是车上手机的位置，浅绿色圆是系统报告的定位误差。电脑网页的“定位到小车”使用车上手机的位置。
3. 直接点击地图，按顺序添加途经点和终点；最后一个点为终点。也可输入 WGS84 经纬度。这里的连线由你指定，不是自动沿道路规划的步行路线；不要直接粘贴未经转换的高德或百度坐标。
4. 设置到达半径，点击“保存航点路线”。可设置最多20点、单段最多1公里、点间总长最多2公里。相邻点间距必须大于到达半径的2倍。路线只在服务器内存保留，重启后消失。

## 开始户外测试

1. 手机固定在小车上，后置摄像头朝车头并能看到前方地面，保证光线充足。
2. 把车头实际对准第1航点方向，点击“车头已对准第1点，校准”。校准参考点须至少20米外，且大于当前定位误差的3倍。重新开启相机来源、重新安装或改变手机固定方式后重新校准；校准30分钟后过期。
3. 手机须报告新鲜的定位和后置摄像头方向，罗盘误差不超过25°；定位误差须小于等于到达半径的一半，且不超过10米。例如，误差9米时需要至少20米到达半径，不能做室内1米级导航。
4. 观察绿色地面判断正确，再点击“开始点到点导航”。默认30%电机指令上限，最高45%；不是实测车速。驾驶操作页和手机采集页都保持前台。
5. PC 计算目标方位与车头差值，在视觉确认的左、中、右通路中选择方向。不会盲目倒车或原地掉头。目标偏离车头超过65°时停止，需要手动调整后重新启动。
6. 距航点的距离加定位误差不超过到达半径时先停车，连续3个不同的新定位确认后进入下一点；最后一点确认后停止导航。重复上传同一定位不会重复计数。

## 随时接管

网页急停、空格、手柄B键停止；手动方向键或手柄油门接管。摄像头、PC或车辆断线，驾驶页切到后台，GPS过期或异常跳变，罗盘不可靠，画面过暗、模糊或没有确认通路时停止自动驾驶。停下后需重新点击启动。

该版本属于“GPS航点指导 + 图像分割选择局部方向”的原型，不提供精确车身定位、距离测量、地图自动算路或完整的障碍绕行规划。遇到阻挡可能停车，需要修改航点或手动绕行。地图精度和普通手机定位无法保证车始终在人行道范围内；在平坦、空旷且允许小车运行的场地有人看管测试。

## 验证情况

已完成离线测试：距离与方位计算、航向跨0°处理、定位与方向过期检查、误差过大拒绝行驶、校准检查、定位跳变拒绝、连续定位到达确认、多航点切换、视觉停车优先。

已完成本地模拟车辆的端到端测试：路线保存、方向校准、PC输出导航指令、导航启动、到达停车、错误路线拒绝和路线清空。测试不连接实车，不使用真实位置；真实户外行驶尚未验证。

底图由浏览器向 https://tile.openstreetmap.org 请求，遵循网页所显示的 OpenStreetMap 署名。底图本身不需要 API Key；高德自动路线使用已在服务器配置的 Key，苹果地图未接入。若底图网络不可用，仍可通过坐标输入编辑航点。
