# 高德自动规划 + PC 视觉驾驶

已配置用户提供的高德 Web 服务 Key，只保存在服务器配置中，不下发到网页。底图继续使用 OpenStreetMap；自动路线、道路折线和转向提示来自高德步行路线接口。

## 使用

1. 车上的 iPhone 刷新原网页，开启本机后置摄像头，并允许定位和运动数据。电脑保持视觉计算程序运行。
2. 网页的“地图点击操作”选择“设置自动规划终点”，直接点击地图选终点；也可输入 WGS84 经纬度后点击“设为规划终点”。起点使用车上 iPhone 的位置。
3. 选择到达半径，再点击“高德自动规划步行路线”。服务器将 GPS 坐标转换为高德坐标，调用高德规划，再把路线转换回网页与 PC 使用的 WGS84 坐标。反向转换采用数值近似，不能作为高精度测绘依据。
4. 检查橙色预览路线、距离、转向提示及警告。点击“使用这条路线”才会替换当前导航任务；仅规划或载入路线都不会启动电机。预览保留10分钟，最多保留4条。
5. 查看地图上的黄色校准参考点，将车头实际对准该参考点方向，手机固定好后点击校准。不要仅把手机转向参考点；需要车头与手机作为整体朝向它。
6. 在光线充足、平坦空旷的户外场地，确认定位、朝向和绿色通路判断正常后，点击“开始点到点导航”。GPS 精度要求、低速限制、手动接管和断线停车继续生效。

## 当前能力与限制

- 高德自动沿道路计算步行路线，PC 根据路线折线选择前方跟踪点，不直接穿越路线拐角朝最终终点走。
- 网页显示沿路线剩余距离、偏离路线距离、目标方向、定位误差。偏离路线超过阈值后停车，需要手动调整或重新规划；不会在行驶中自动改换路线。
- 到达终点的定位容差范围后停车，连续3次新的定位确认后结束任务。定位误差较大时，到达范围也必须相应增大，不能保证米级停靠。
- 高德会将起终点匹配到步行路网上。网页显示匹配端点与所选起终点的距离；实际导航终点采用可通行路网的匹配端点。任一端偏离路网超过20米时阻止自动执行，不凭空添加穿越建筑或草地的连接线。
- 对已标出的台阶、天桥、特殊通道、扶梯、轮渡等路段阻止自动执行。地图可能漏标，步行可通过也不等于小车可通过，仍需人工检查和视觉判断。
- 只支持2公里内路线。目标超出车头65°时仍会停止，可能需要手动调整车头后重新启动。未验证的小车转弯能力和普通手机定位精度仍会限制自动驾驶效果。
- 手动航点功能保留，切换“添加手动航点”即可使用。保存手动路线会清除之前导入的高德道路路线。

## 已验证

高德坐标转换和步行路线接口均成功；公网服务器通过新接口完成了一条公共测试坐标的70米路线规划，返回9个道路形状点和3条导航提示。测试仅生成预览，没有载入实车任务，也没有启动电机。

自动路线跟踪已通过模拟测试：沿首段道路而非直奔终点、偏离路线停车、U形路线不提前判定到达、不适合小车的路段禁止启动。真实户外自主驾驶仍待测试。
