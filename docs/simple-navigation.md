# 简化导航与手持手机测试

## 车辆导航

1. 在车上的手机允许定位与运动权限，开启后置摄像头。手机固定不动，当前沿车尾镜头方向倒行。
2. 搜索地名并选择终点，点击“规划路线并载入”。地图显示路径，路线自动拆成前进、左右转向和距离指令。
3. 点击“按路线驾驶（自动对齐）”。Safari 绝对罗盘朝向有效时，不需要手工对准参考点校准；方向偏差较大时自动调整方向，然后持续用定位、朝向和视觉修正。

路线不是按估计秒数盲跑。实际执行仍需要有效定位、朝向和可走通路；默认测试模式不因 GPS 误差大或朝向精度不足而单独停车，定位有效窗口为30秒，朝向仍需1500毫秒内更新。方向权限未授权、数据过期或路线包含限制路段时，网页显示具体原因。当前为测试原型，尚未完成真实户外全路线验证。

## 手持手机测试

规划路线后，在手持手机上点击“手持手机测试（不驱动电机）”，允许定位与运动权限，让手机镜头朝向行进方向，按网页提示步行。

此模式不需要开启摄像头，也不需要车辆在线。服务器锁定车辆的手动、自动和大胆测试驾驶入口，只输出建议方向、本段距离、位置和朝向。结束手持测试后，才能重新操作电机。

手持测试可展示较粗定位或车辆不可执行路段的步行导航提示，不会解除车辆的路线限制。

## Safari 定位

Safari 支持持续定位，不是只返回一次。网页使用 watchPosition 持续监听，位置较旧时额外请求一次新定位；长时间没有回调时重建监听。原始测量时间保留，重复发送同一个旧位置不会被伪装成新定位。

页面显示定位回调次数、新定位次数、最近定位年龄、误差和错误。保持页面前台并避免锁屏；切到后台的网页不能保证持续定位。传感器的实际更新频率和精度仍由手机系统决定。

## 固定功率

自动直行按设定功率输出，默认80%、上限100%；取消视觉油门比例和通路评分波动降功率。转向仍通过左右轮差速实现。大胆测试保持80%、按住运行、每轮最多8秒。

偏暗和路面颠簸本身不触发停车。自主找路模式遇到无通路时旋转0.6秒、停0.3秒观察，最多尝试6秒；一帧通路确认即恢复，旧画面不用于旋转。导航模式不会用旋转找路绕过路线或定位暂停。定位失效、急停和断连保护仍生效。固定功率不等于实际车速恒定。
